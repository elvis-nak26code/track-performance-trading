# Captures de la landing page BlackTracker

Déposez ici vos captures d'écran **avec exactement ces noms** (PNG ou JPG,
mais gardez l'extension `.png` ci-dessous ou adaptez `SHOTS` dans
`src/pages/Landing.jsx`) :

- `dashboard.png` — Tableau de bord (hero de la landing)
- `journal.png` — Page libre du journal
- `analytics.png` — Page Analytics
- `calendar.png` — Page Calendrier

Tant qu'un fichier est absent, la landing affiche automatiquement un
placeholder élégant à la place (aucune erreur visible pour le visiteur).

Astuce : capturez en mode sombre, en 16/9, sans la barre d'URL du navigateur.
